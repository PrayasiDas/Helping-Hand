# 🤝 Helping Hand

**Lend a hand, change a life.**

Helping Hand is a web app that connects people with NGOs. Users can search for NGOs, find the nearest ones, and donate.

🔗 **Live demo:** https://prayasidas.github.io/Helping-Hand/

## Features
- Search NGOs by name, cause, or location
- Find Nearest NGOs using your location
- Donate Now option
- login and Register option
- chat with ngo option
- Multi-language support (English, Hindi)

## Built With
- HTML
-  CSS
- JavaScript

## How to Run Locally
1. Clone the repo:
   `git clone https://github.com/PrayasiDas/Helping-Hand.git`
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
